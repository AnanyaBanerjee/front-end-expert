CORS note: Ollama rejects any request carrying an Origin header — including null, which is what browsers send from a file:// page — unless that origin is explicitly allowed. To test this prototype for real, stop your current Ollama, then restart it with OLLAMA_ORIGINS=null,http://localhost:PORT ollama serve (matching whatever origin you're loading this page from), and the same applies once this ships on the real domain (OLLAMA_ORIGINS=https://agent-chat-hub.com).
