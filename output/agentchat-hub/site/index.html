FAQ

Questions worth answering.

01 What is the A2A protocol?
+
A2A (Agent-to-Agent) is an open interoperability protocol that lets AI agents communicate across platforms using a standard HTTP interface. Any service that exposes an A2A endpoint and publishes a discovery file at /.well-known/agent.json is automatically compatible with AgentChat Hub.
02 Which agents can I connect to?
+
Any agent that implements the A2A specification — ones you build yourself, internal company agents, or any third-party service exposing a standard A2A endpoint. There is no curated marketplace. The open web is the directory.
03 Is AgentChat Hub really free?
+
Yes. No subscription, no in-app purchases, no freemium gate. The app is free on the App Store. You pay the agent providers you connect to directly — that's between you and them.
04 Does AgentChat see my conversation data?
+
No. AgentChat Hub has no backend, no telemetry, and no analytics. Messages travel directly from your device to your chosen agent — we are not in that path. Conversations are stored on-device and nowhere else.
05 Do I need to build anything to use it?
+
No. If you already have an A2A-compatible agent endpoint — or you find one on the open web — you just paste the URL and start chatting. No SDK, no custom frontend to build. Prefer a cloud model instead? Bring your own API key for Claude, OpenAI, Grok, Kimi, or DeepSeek — no A2A endpoint required.
06 What AI agents work with AgentChat Hub?
+
Any agent that implements the A2A specification and exposes an endpoint — including agents built with LangChain, CrewAI, custom Python or Node.js servers, locally-run models wrapped in an A2A layer, and any internal company agent. If it publishes an Agent Card, AgentChat Hub can connect to it.
07 Is AgentChat Hub available on Android?
+
Not yet — but Android is coming soon. AgentChat Hub is currently available as a native app on iPhone, iPad, Mac, and Vision Pro. Stay tuned for the Android release.
08 Is AgentChat Hub a privacy-focused AI chat app?
+
Yes. AgentChat Hub has no backend, no analytics, and no telemetry. Messages travel directly from your device to your AI agent — nothing passes through our servers. Conversations are stored on-device only. No data is collected, shared, or sold. Privacy is not a setting you toggle; it is the default architecture.
09 Can I send files to my AI agent?
+
Yes. You can send files to your AI agent directly from any conversation in AgentChat Hub — photos, images, and documents drop in inline. Your agent receives the actual file, not a description of it. No separate upload flow, no copy-pasting. Multimodal support is built in from the start.
10 How does AgentChat Hub compare to other AI chat clients?
+
Most AI chat apps lock you into one provider's model. AgentChat Hub connects three ways — any A2A-compatible agent via URL, cloud providers like Claude, OpenAI, Grok, Kimi, or DeepSeek with your own key, or local models via Ollama and LM Studio. No curated marketplace, no vendor lock-in. Key differentiators: MCP tool support, goal-driven Tasks, real-time SSE token streaming, file attachments, no account required, zero data collection, native binary on iPhone, iPad, Mac, and Vision Pro.
11 What is MCP and does AgentChat Hub support it?
+
MCP (Model Context Protocol) is the open standard for giving AI agents tools. AgentChat Hub connects any agent to MCP servers — add a server once, attach it to whichever agents need it, and get real function-calling against those tools, including OAuth-authenticated servers.
12 Do I need an API key to use AgentChat Hub?
+
Only if you choose the Cloud AI connection method. To chat with Claude, OpenAI, Grok, Kimi, or DeepSeek directly, bring your own API key — it lives in your device's Keychain and is sent only to that provider. Connecting an A2A agent or a local model requires no API key at all.
13 Can I run local AI models with AgentChat Hub?
+
Yes. Point AgentChat Hub at Ollama or LM Studio running on your own machine or network, and it discovers exactly which models you have installed. No API key, no cloud round-trip — the model runs entirely on your hardware.
