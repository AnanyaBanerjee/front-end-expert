Local AI

You downloaded a local model. Now make it part of your day.

A local model can be useful for everyday drafting and brainstorming. AgentChat Hub gives a compatible model server a familiar chat interface, so returning to it becomes part of your routine.

The problem: you set it up, then stopped reaching for it

You downloaded a model because you wanted more control over where your prompts go. You tried it, got a response, and proved it works. A week later, you are still opening your usual cloud chat out of habit.

The model is there. What is missing is a comfortable place to use it alongside the rest of your AI tools.

Connect the server you already run

AgentChat Hub connects to compatible local model servers, including Ollama and LM Studio. It supplies the chat interface; it does not download models or run inference itself. The server and model need to be running separately.

  1. Start your chosen local server and make sure a model is available.
  2. In AgentChat Hub, open Add Agent → Local Server.
  3. Enter the server address and any credentials your server requires.
  4. Use Test Connection, choose an available model, and add the agent.
  5. Open its chat and try a small, ordinary task.

For example, paste a few rough notes about an event you are planning and ask for a checklist:

“Organize these notes into a checklist. Group related items and flag anything that needs a decision. Use only the information I provide.”

Review the answer, ask follow-up questions, and return to the same conversation when you need it. This is an example of a possible workflow, not a promise about any particular model’s output.

What this resolves

Your local model becomes an agent you can find in the same workspace as your other connections. You have a consistent place to chat and a conversation history on your device. The model’s speed and capabilities still depend on the model and the machine running it.

Local is about the whole connection

With a model running locally, your prompts are processed by that server. Selecting a cloud-hosted model or attaching a remote tool can send information elsewhere. AgentChat Hub collects no conversation data, but it cannot change the behavior of a server or tool you connect.

Ollama’s default server listens on your computer’s loopback address. Connecting from an iPhone requires a server address reachable from the phone, with appropriate network access and protection. localhost on the phone means the phone, not your Mac. See the Ollama FAQ for local/cloud behavior and network configuration.

If you use LM Studio, its server documentation explains how to start a local API server. Keep the server running while you use it through AgentChat Hub.

A couple of questions

Does AgentChat Hub run the model on my iPhone?+

No. It connects to the model server you configure. The server runs the model and must be reachable from the phone.

Is every local-server connection fully offline?+

No. That depends on the server, the model, and any tools it uses. A local model without external dependencies can work without a cloud AI provider, but the app must still reach the server.

Try it with your own connection.
