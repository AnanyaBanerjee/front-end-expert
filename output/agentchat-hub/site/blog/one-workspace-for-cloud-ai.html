The problem: the work is in one project, but the conversations are everywhere

You are preparing a project update. One model helps you turn rough notes into a draft. You ask another to find the gaps in your reasoning. Later, you want to revisit a suggestion, and you are back to searching through different apps and browser tabs.

Choosing different models can be useful. Remembering where you left each conversation is the extra work.

Use one workspace for the models you already choose

AgentChat Hub lets you add supported cloud providers using your own API keys. Each connection becomes an agent you can return to in the same app. You can put related agents in a group, such as “Writing” or “Project planning,” so your workspace reflects the work you do.

Here is an illustrative workflow for that project update:

  1. Open Add Agent → Cloud AI and choose a supported provider.
  2. Add your own API key and select the model available through that connection.
  3. Create another connection for a second provider if you use one.
  4. Put the agents in a project group and start a separate conversation with each.

Ask the first agent to organize your notes. Then take the draft you want reviewed into a conversation with the second agent. You decide what to share between conversations; the app does not automatically combine their memories or compare their answers.

“Turn these notes into a project update. Separate what is finished, what is blocked, and the decisions I need help with. Do not invent missing details.”

That is a sample prompt you can adapt. The quality of the result still depends on your chosen model and the information you provide.

What this resolves

Your providers remain different, but the place you go to use them becomes consistent. You can return to each agent from one roster and organize connections by purpose. AgentChat Hub does not import the chat history from your existing provider apps; this workspace starts with the conversations you create here.

Know what you are connecting

AgentChat Hub is free to use. Cloud API usage is billed by the provider, and a chat subscription does not necessarily include API access. Check your provider account before connecting. For Claude, see the official API access guide.

AgentChat Hub does not collect your conversation data. Your messages still go to the provider you select, and that provider’s data policies apply.

A couple of questions

Does this merge my existing AI chat histories?+

No. AgentChat Hub keeps conversations created in the app. It does not import or merge the history from your provider apps.

Can the models automatically see each other’s answers?+

No. These are separate conversations. You choose which text or context to share with another agent.

Try it with your own connection.

AgentChat Hub is free. Bring a compatible agent, a supported cloud API key, or a local model server.
