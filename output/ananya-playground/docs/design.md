# Creator’s playground — first visual slice

Approved direction: option 1, 2026-09-18. Scope: opening composition and one featured venture interaction, then visual review before the full portfolio is rebuilt.

## Design context

Audience: people discovering Ananya’s products, creative work, and AI ecosystem. The opening should communicate a prolific, curious person through real work. The previous draft failed through repetitive cards, uniform spacing, and neutral typography.

## Tokens and composition

- Paper: #f5f6f2; ink: #26232b; muted: #636568; lilac: #c5b8ed; yellow: #f5da72; ocean: #113f4c.
- Display: Anybody expanded 800, for the name and large project headings. Text: Chivo 400/500, for straightforward reading and compact captions.
- A large name forms the center of an asymmetric composition. Real product windows and phone screens occupy different depths around it. Captions and a small portrait identify the person and projects without adding a label above every heading.
- Tight typographic composition in the opening, followed by a generous pause before a full-width Thought Escape world. No repeated card grid in this slice.
- Motion: a single entrance composition; pointer/focus opens up each artifact and reveals a label. Thought Escape switches between four real worlds with a crossfade; reduced motion uses immediate changes. No decorative perpetual animation.

## Self-critique

The distinct choice is the name-and-product composition, supported by the actual brands. Avoid extra badges, stamps, generic symbols, fake quotes, invented app interfaces, and background effects. Preserve a readable name and obvious destinations. On mobile use a compact grid of actual artifacts beneath the name rather than positioning them over text.

## Verification and review

Local-only preview in a separate project directory. Reuse existing verified product links and media. Check all local references, metadata, keyboard controls, world-selection state, and JavaScript syntax. Do not claim browser checks that were not performed. Retain the old portfolio unchanged.
